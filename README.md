Cổng thông tin điện tử & Dịch vụ sinh viên chính thức của **Khoa Tài Chính Ngân Hàng - Trường CNTT&TT**. Xây dựng trên nền tảng **Next.js 16 (React 19)** hiện đại, hỗ trợ đa ngôn ngữ (`next-intl`), tối ưu hóa SEO và hiệu năng cao.

---

## ✨ Tính Năng Nổi Bật

- 📰 **Tin Tức & Sự Kiện:** Cập nhật tin tức tuyển sinh, hoạt động khoa, hội thảo khoa học.
- 🎓 **Chương Trình Đào Tạo:** Tra cứu lộ trình học phần, giảng viên, bộ môn tài chính.
- 📄 **Cổng Dịch Vụ Sinh Viên:** Đăng ký mẫu đơn, xem biểu mẫu, tra cứu lịch thi & thông báo.
- 🌐 **Đa Ngôn Ngữ (i18n):** Hỗ trợ Tiếng Việt & Tiếng Anh qua `next-intl`.
- ⚡ **SEO & Performance:** Server-Side Rendering (SSR) & Static Site Generation (SSG) với Next.js App Router.

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend Framework:** Next.js 16 (App Router), React 19
- **Ngôn ngữ:** TypeScript
- **Styling:** Tailwind CSS, Radix UI / Shadcn UI components, Lucide Icons
- **Đa ngôn ngữ:** `next-intl`
- **HTTP Client:** Axios / Fetch API

---

## 🚀 Hướng Dẫn Cài Đặt & Chạy Lập Trình

```bash
# 1. Clone repository
git clone https://github.com/nguyenhuynhdt37/ktcn-client-frontend.git
cd ktcn-client-frontend

# 2. Cài đặt các thư viện phụ thuộc
npm install

# 3. Chạy môi trường Development
npm run dev
```

Mở trình duyệt tại: `http://localhost:3000`
